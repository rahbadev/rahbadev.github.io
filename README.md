## 🎨 التخصيص

### 1. تغيير المعلومات الأساسية

افتح `index.html` وعدل:
```html
<!-- المعلومات في head -->
<title>اسم شركتك</title>
<meta name="description" content="وصف شركتك">

<!-- معلومات التواصل -->
<a href="mailto:your-email@example.com">
<a href="https://wa.me/YOUR_NUMBER">
```

### 2. تغيير الألوان

افتح `assets/css/main.css` وعدل المتغيرات:
```css
:root {
    --primary-color: #2d6ac8;    /* اللون الأساسي */
    --secondary-color: #3d7fd9;   /* اللون الثانوي */
    --accent-color: #5ca3e8;      /* لون التمييز */
}
```

### 3. تعديل الخدمات

افتح `data/services.json` وعدل أو أضف خدمات:
```json
{
    "id": "service-id",
    "title": "عنوان الخدمة",
    "icon": "fas fa-icon-name",
    "description": "وصف الخدمة",
    "features": ["ميزة 1", "ميزة 2"],
    "startingPrice": 100,
    "targetAudience": "الفئة المستهدفة"
}
```

### 4. تغيير الشعار

استبدل الملفات في `assets/images/`:
- `brand.webp` - شعار الشركة (يفضل 1500×900 بكسل)
- `icon.ico` - أيقونة الموقع

## 🔨 نظام البناء

نظام بناء تلقائي لإنشاء صفحات المشاريع:

### إضافة مشروع جديد

```bash
# 1. أنشئ مجلد المشروع
mkdir projects/my-new-project

# 2. أنشئ ملف info.json
# انسخ من _templates/info.json.example

# 3. شغل البناء
node build.js
```

### ملف info.json

```json
{
  "name": "اسم المشروع",
  "slug": "project-slug",
  "category": "apps",
```

## ❓ الأسئلة الشائعة

**س: كيف أغير رقم الواتساب؟**
ج: ابحث عن `wa.me/` في `index.html` واستبدل الرقم

**س: كيف أضيف صورة لمشروع؟**
ج: ضع الصور في `projects/[project-name]/screens/`

**س: هل يمكن استخدام الموقع بدون Node.js؟**
ج: نعم! افتح `index.html` مباشرة. Node.js فقط لنظام البناء

**س: كيف أحذف قسم؟**
ج: احذف القسم من `index.html` والتنسيقات من `main.css`

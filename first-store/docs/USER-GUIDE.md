## 1. تغيير معلومات المتجر

### 📍 أين أعدل؟
افتح الملف: `public/config.js`

### ✏️ ماذا أعدل؟
ابحث عن القسم الأول:

```javascript
store: {
    name: 'متجر الهواتف الذكية',     // اسم متجرك هنا

    tagline: 'أفضل الأجهزة بأفضل الأسعار',  // الشعار القصير
    
    description: 'أفضل الأجهزة الجديدة والمستعملة...',  // الوصف الكامل
```

### 🎯 مثال:
```javascript
store: {
    name: 'متجر الإلكترونيات',
    tagline: 'كل ما تحتاجه في مكان واحد',
    description: 'نوفر أفضل المنتجات الإلكترونية بأسعار منافسة',
```

## 2. تغيير رقم الواتساب

### 📍 أين أعدل؟
في نفس الملف: `public/config.js`

### ✏️ ماذا أعدل؟
ابحث عن:

```javascript
contact: {
    whatsapp: '966500000000',  // 👈 ضع رقمك هنا بدون + أو مسافات
    
    displayPhone: '+966 50 000 0000',  // 👈 رقمك للعرض فقط
```

### ⚠️ مهم جداً:
- احذف علامة `+` والمسافات من الرقم الأول
- الرقم الثاني للع specs فقط (كيف يظهر للعملاء)

### 🎯 مثال:
إذا كان رقمك: **+966 55 123 4567**

```javascript
contact: {
    whatsapp: '966551234567',         // بدون + وبدون مسافات
    displayPhone: '+966 55 123 4567',  // مع + ومع مسافات
```

## 3. تغيير الألوان والمظهر

### 📍 أين أعدل؟
في `public/config.js`

### ✏️ ماذا أعدل؟
ابحث عن:

```javascript
theme: {
    colors: {
        primary: '#3b82f6',  // اللون الأساسي (أزرق)
        secondary: '#8b5cf6',  // اللون الثانوي (بنفسجي)
        success: '#10B981',  // الأخضر
        error: '#EF4444',  // الأحمر
    }
}
```

### 🎨 كيف أختار الألوان؟
1. اذهب إلى: https://htmlcolors.com/
2. اختر اللون الذي يعجبك
3. انسخ الكود (مثل: `#FF5733`)
4. ضعه مكان اللون القديم

### 🎯 مثال:
```javascript
colors: {
    primary: '#FF5733',  // برتقالي
    secondary: '#C70039',  // أحمر غامق
}
```

## 4. تغيير شكل عرض المنتجات

### 📍 أين أعدل؟
في `public/config.js`

### ✏️ ماذا أعدل؟
ابحث عن:

```javascript
layouts: {
    productCard: 'modern',  // 👈 غير هذا
    
    categoryFilter: 'tabs',  // شكل الفئات
    
    searchBar: 'embedded',  // شكل البحث
}
```

### 🎨 الخيارات المتاحة:

#### شكل بطاقات المنتجات (`productCard`):
- `'modern'` - عصري وأنيق ✨
- `'classic'` - تقليدي 📦
- `'minimal'` - بسيط جداً  🎴
- `'detailed'` - تفصيلي 📋
- `'compact'` - مضغوط (يدخل أكثر) 📐

#### شكل الفئات (`categoryFilter`):
- `'tabs'` - تبويبات 📑
- `'buttons'` - أزرار 🔘
- `'dropdown'` - قائمة منسدلة 📌
- `'chips'` - رقائق 🎫
- `'sidebar'` - شريط جانبي 📊

### 🎯 مثال:
```javascript
layouts: {
    productCard: 'minimal',  // بسيط
    categoryFilter: 'buttons',  // أزرار
}
```

جرّب كل خيار وشوف الأنسب لمتجرك!

## 5. إضافة وتعديل المنتجات

### 📍 كيف أدير المنتجات؟

#### الطريقة 1: لوحة التحكم (سهلة)
1. افتح: `admin/index.html`
2. سجّل دخول
3. اضغط "إضافة منتج"
4. املأ المعلومات:
   - اسم المنتج
   - العلامة التجارية
   - السعر
   - ارفع صورة
   - الوصف
5. اضغط "حفظ"

#### الطريقة 2: مباشرة في قاعدة البيانات
1. اذهب إلى Supabase (الموقع الذي أعطاك إياه المطور)
2. سجّل دخول
3. اذهب لجدول `products`
4. اضغط "Insert" لإضافة منتج جديد
5. املأ البيانات

## 6. تخصيص رسائل الواتساب

### 📍 أين أعدل؟
في `public/config.js`

### ✏️ ماذا أعدل؟
ابحث عن:

```javascript
whatsapp: {
    orderMessage: 'مرحباً، أنا مهتم بـ {productName}',
    
    inquiryMessage: 'مرحباً، لدي استفسار عن متجركم',
}
```

### 🎯 المتغيرات المتاحة:
يمكنك استخدام هذه الكلمات السحرية:
- `{productName}` - اسم المنتج
- `{brand}` - العلامة التجارية
- `{price}` - السعر
- `{condition}` - الحالة (جديد/مستعمل)

### 📝 أمثلة:

```javascript
// رسالة رسمية
orderMessage: 'السلام عليكم، أرغب في شراء {brand} {productName} بسعر {price}. هل هو متوفر؟'

// رسالة ودية
orderMessage: 'هلا 👋 معايا {productName} بكم؟'

// رسالة تفصيلية
orderMessage: 'مرحباً، شفت عندكم {brand} {productName} ({condition}) السعر {price}. ممكن تفاصيل أكثر؟'
```

## 7. ما لا يجب تعديله ⛔

### ❌ لا تعدل هذه الأقسام:

#### في `config.js`:
```javascript
database: {
    url: '...',  // ❌ لا تغير
    anonKey: '...',  // ❌ لا تغير
}

images: {
    cloudName: '...',  // ❌ لا تغير
}
```

#### المجلدات:
- ❌ `src/` - لا تفتحها أبداً
- ❌ `assets/` - لا تعدل فيها
- ✅ فقط عدّل في: `config.js`

## 🆘 مساعدة سريعة

### المشكلة: المتجر لا يعمل بعد التعديل

**الحل:**
1. تأكد أنك عدلت في `config.js` فقط
2. تأكد أنك لم تحذف أي علامات ، أو {} أو ""
3. ارجع للنسخة الأصلية وابدأ من جديد

### المشكلة: الألوان لا تتغير

**الحل:**
1. امسح الكاش (Ctrl + F5)
2. تأكد من الكود يبدأ بـ `#`
3. تأكد من 6 أرقام/حروف بعد `#`

### المشكلة: رقم الواتساب لا يعمل

**الحل:**
1. تأكد أنك حذفت `+` والمسافات
2. تأكد الرقم يبدأ بـ `966`
3. مثال صحيح: `966551234567`

## ✅ نصائح مهمة

1. **احتفظ بنسخة احتياطية** قبل أي تعديل
2. **عدّل شيء واحد** في كل مرة وجرّب
3. **لا تحذف الفواصل والأقواس** (، : {} "")
4. **استخدم نفس الصيغة** الموجودة
5. **اسأل المطور** إذا تعطل شيء
